# Коммерческий Volkswagen: получение контрольных образцов заводской информации

## Канал запроса

Страница поставщика: https://com.vw-maximum.ru/owners/service/repair-tech/

Опубликованные правила:
- запрос принимается от независимой СТО — юридического лица или ИП;
- один запрос = один автомобиль (VIN) и один тип информации;
- доступны категории: техническая информация, снятие/установка, разборка/сборка, электрическая схема;
- сведения по системам безопасности не предоставляются;
- результат отправляется на e-mail после безналичной оплаты;
- на странице указана стоимость 1 400 рублей с НДС за запрос;
- правообладателем информации назван VOLKSWAGEN AG;
- поставщик указывает, что сведения передаются как есть, без адаптации и проверки.

## Что запросить для пилота

Для проверки качества источника нужны минимум три отдельных запроса на реальные автомобили коммерческого семейства VW, но только если у СТО есть законное основание использовать соответствующие VIN и оплатить запросы:

1. **Техническая информация** — предпочтительно документ, где есть идентификация модели, модельного года, кода двигателя и технические параметры конкретного агрегата.
2. **Снятие/установка или разборка/сборка** — для узла, где есть последовательность работ, специальные инструменты, моменты затяжки и ограничения применимости.
3. **Электрическая схема** — для конкретного блока/цепи с обозначением модели, двигателя/комплектации, легендой компонентов, соединителей и точек массы.

Не запрашивать документы по системам безопасности: опубликованные правила прямо исключают их из услуги.

## Рекомендуемые критерии выбора трёх VIN

Выбирать разные по поколению/году/силовому агрегату машины, чтобы проверить глубину применимости, а не получить три одинаковых отчёта. Не отправлять VIN в публичный GitHub, issue, commit или отчёт. Для анализа использовать локальные обезличенные идентификаторы Sample A/B/C.

## Карточка приёма каждого образца

| Поле | Что зафиксировать |
|---|---|
| sample_id | SAMPLE-A / SAMPLE-B / SAMPLE-C |
| vehicle_make_model | Как указано в документе |
| model_year / production_date | Только если явно указано |
| type_code / VIN scope | Сохранить точный VIN только локально, в защищённом хранилище |
| engine_code | Только буквенно-цифровой код, прямо указанный в документе |
| gearbox_code | Только если указан |
| document_title / document_id | Заголовок и ID |
| document_revision / issue_date | Ревизия и дата |
| document_type | technical_info / removal_installation / disassembly_assembly / wiring_diagram |
| ecu_part_number / HW / SW | Только если документ действительно содержит эти поля |
| wiring_connector / pin / wire_color | Только для электрической схемы, с координатой листа/страницы |
| torque_values / special_tools | Только если указаны в процедуре |
| evidence_locator | Страница, раздел, таблица, схема или абзац |
| source_file_sha256 | Хеш оригинального файла, если его хранение разрешено |
| reuse_permission | Письменное разрешение на хранение/извлечение/публикацию — отдельное поле |
| review_status | candidate → header_verified → applicability_verified → engineer_reviewed |

## Как оценивать образцы

### Техническая информация
Проверить, есть ли тип автомобиля, двигатель, КПП, технические значения с единицами, условия измерения, допуски, рынок, даты выпуска и документная ревизия. Значение без условий и единиц нельзя импортировать как норматив.

### Снятие/установка и разборка/сборка
Проверить точную последовательность, одноразовый крепёж, специальные инструменты, моменты затяжки/углы, предупреждения, условия подъёма/опоры и применимость к коду двигателя/КПП. Не превращать OCR-ошибки в инструкции.

### Электрическая схема
Проверить номер схемы/листа, дату/ревизию, тип автомобиля, конкретную комплектацию, адрес ECU, обозначения разъёмов и контактов, сечения/цвета проводов, соединения, точки массы, splice points и легенду. Нельзя собирать распиновку из картинки без проверки всех страниц и легенды.

## Правовой шлюз

Покупка одного документа не означает право включить его PDF, изображение, текст процедуры или схему в автономное приложение. До публикации структурированных фактов нужно получить письменное разъяснение:
1. разрешено ли хранить исходный PDF во внутренней базе;
2. разрешено ли извлекать минимальные структурированные технические факты;
3. разрешено ли распространять эти факты вместе с некоммерческим приложением;
4. разрешено ли включать схемы, распиновки, моменты затяжки и шаги процедуры;
5. какие требования к атрибуции, обновлению и удалению применяются.

До письменного разрешения оригинальные документы и производные сведения не публиковать. В репозитории хранить только обезличенный audit report, разрешённые метаданные и хеши, если это допускается условиями.

## Ограничение текущего этапа

Реальные VIN и образцы документов не получены. Для получения требуется заявка от СТО — юридического лица или ИП, законно используемые VIN коммерческих VW и оплата поставщику. Ассистент не должен выдумывать образцы или утверждать, что документы получены. Следующий вход от владельца проекта: подтвердить наличие такого заявителя и трёх доступных VIN; сами VIN отправлять непосредственно поставщику, не в публичный репозиторий.
