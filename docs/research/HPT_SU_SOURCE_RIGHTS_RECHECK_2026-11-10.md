# HPT.SU — повторная проверка прав на ОТТС/API

Дата проверки: 10 ноября 2026 года. Проверялись опубликованные условия доступа и использования; запросы к API/MCP и получение документов не выполнялись.

## Вывод

HPT.SU остаётся коммерческим агрегатором документов соответствия RU/EAEU. Условия не предоставляют VAG TECH PRO лицензию на создание распространяемой offline-базы из записей HPT.SU.

**Решение:** no account, no API key, no subscription, no payment, no API/MCP requests, no downloads, no SQLite import. Источник остаётся restricted для product distribution.

## Существенные положения

### Отдельные документы и собственные нужды

Оферта §11.3 разрешает в пределах законно предоставленного доступа просматривать, сохранять локально и использовать отдельные полученные материалы в собственной деятельности, обрабатывать содержание отдельных документов автоматизированно для собственных нужд и цитировать его в пределах закона. §11.5 уточняет, что это не отменяет ограничений на способ и объём извлечения из базы.

### Ограничения базы и распространения

Оферта §11.4 запрещает без письменного согласия:
- массовое автоматизированное скачивание в обход штатных интерфейсов/лимитов;
- извлечение существенной части базы либо систематическое извлечение несущественных частей, способное повредить законным интересам оператора;
- создание производных баз, существенно воспроизводящих HPT.SU и конкурирующих с его сервисом.

API terms §6.2 допускают внутреннюю интеграцию и собственную аналитику, если производный продукт не предоставляет третьим лицам доступ, эквивалентный базе HPT.SU. §6.3 запрещает без отдельного письменного согласия эквивалентный доступ третьим лицам, существенное воспроизведение производной базы и передачу данных через собственные API/веб-интерфейсы/выгрузки.

### Узкая оговорка о собственных аналитических результатах

API terms §6.4 разрешают предоставлять третьим лицам результаты собственной аналитической работы только при одновременном соблюдении условий:
1. результат не является простым переупаковыванием полученных через API данных;
2. объём и состав существенно меньше базы HPT.SU;
3. при публикации указывается ссылка на источник.

Эта оговорка не является разрешением распространять локальную базу ОТТС, кешировать записи HPT.SU для клиентов VAG TECH PRO или предоставлять им функциональность, эквивалентную доступу к HPT.SU. §8.6 отдельно запрещает систематический перенос полной актуальной копии базы в собственное хранилище.

## Что это означает для VAG TECH PRO

Платная API-подписка сама по себе не снимает ограничений на третьестороннее распространение. Встроенный в установщик SQLite-каталог с данными HPT.SU был бы предоставлением данных третьим лицам и потенциально существенным воспроизведением базы. Для такого сценария нужно отдельное письменное согласие, прямо разрешающее массовое получение, хранение, offline-кеширование, отображение в Windows desktop и распространение данных конечным пользователям.

Ограниченная аналитическая публикация по §6.4 теоретически возможна только для собственного результата, который не переупаковывает данные, существенно меньше базы и содержит атрибуцию. Это не основание для импорта записей в ремонтный каталог.
